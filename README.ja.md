# Friend

[English](README.md)

フレンドどうしで共有チェストを使い、承認なしでテレポートできるMinecraftサーバー用プラグインです。

- **共有チェスト**: フレンド1組ごとに専用のチェストがあり、`/friend chest <プレイヤー名>` でどこからでも開けます。2人で同時に開いてリアルタイムに出し入れできます。
- **直接テレポート**: `/friend tp <プレイヤー名>` で、相手の承認なしにフレンドのところへ直接テレポートできます。
- **経済連携（Vault）**: Vault経由で、フレンドになるときに双方が支払う手数料を設定できます（任意）。

## 動作環境

- Spigot または Paper 1.20.4 以降（Paper 1.20.4・26.2・26.3 で動作確認）
- Java 17 以降（サーバーの版が求める版）
- 任意: 手数料を取るなら [Vault](https://github.com/MilkBowl/Vault) と経済プラグイン（EssentialsXなど）

## 導入

1. [Releases](https://github.com/spa77k/mc-friend/releases) から `friend-1.0.1.jar` をダウンロードします。
2. サーバーの `plugins/` フォルダに置きます。
3. サーバーを再起動します。`plugins/Friend/config.yml` が生成されます。
4. メッセージを日本語にする場合は、`config.yml` の `language` を `ja` に変更してサーバーを再起動します。

## コマンド

基本コマンド: `/friend`（エイリアス: `/friends`）

| コマンド | 説明 |
| --- | --- |
| `/friend` | コマンドの使い方を表示 |
| `/friend add <プレイヤー名>` | フレンド申請を送る（相手がオンラインのときのみ。相手から申請が届いている場合は承認） |
| `/friend accept [プレイヤー名]` | フレンド申請を承認する（申請が1件のみの場合は名前を省略可能） |
| `/friend deny [プレイヤー名]` | フレンド申請を拒否する（申請が1件のみの場合は名前を省略可能） |
| `/friend list` | フレンド一覧（オンライン/オフライン状態）と届いている申請を表示 |
| `/friend chest <プレイヤー名>` | そのフレンドとの共有チェストを開く |
| `/friend tp <プレイヤー名>` | そのフレンドへテレポートする |
| `/friend remove <プレイヤー名>` | フレンドを解消する（共有チェストを空にして閉じている必要があります） |

### 申請と手数料

- 申請は `request-timeout` 秒で期限切れになります。サーバー再起動時にも消去されます。
- 相手から申請が届いているときに `/friend add <プレイヤー名>` を実行すると、承認として成立します。
- 承認時に双方が設定額の手数料を支払います。どちらかの所持金が足りない場合はフレンドにならず、お金も引かれません。
- 解消は無料で、支払った手数料は返金されません。

### 共有チェスト

- フレンド1組ごとに1つのチェストが用意され、どこからでも開けます。
- 2人で同時に開いてもリアルタイムに同じ内容が表示されます。操作のたび、および閉じたときに自動保存されます。
- チェストにアイテムが残っている間や、どちらかが開いている間は、アイテム消失を防ぐためフレンドを解消できません。

### テレポート

- `teleport-delay` 秒その場から動かずに待つとテレポートします。動くかダメージを受けるとキャンセルされます。
- 相手がオンラインのときのみテレポートできます。

## 権限

| 権限 | 既定値 | 説明 |
| --- | --- | --- |
| `friend.use` | 全員 | すべての `/friend` コマンドを使用可能 |
| `friend.free` | なし | 手数料なしでフレンドになる（本人の支払い分のみ免除） |

## 設定

`plugins/Friend/config.yml`

| キー | 既定値 | 説明 |
| --- | --- | --- |
| `language` | `en` | 使用するメッセージファイル（`messages_<language>.yml`）。`en` と `ja` を同梱。 |
| `fee` | `500` | フレンド成立時に双方が支払う額（`0` で無料）。Vault と経済プラグインが必要（未導入時は常に無料）。 |
| `max-friends` | `10` | 1人あたりのフレンド上限数。 |
| `request-timeout` | `300` | 申請の有効期限（秒）。 |
| `chest-rows` | `3` | 共有チェストの行数（1〜6行、9〜54スロット）。減らすと、はみ出した中身のあるチェストは開けなくなります。 |
| `teleport-delay` | `3` | テレポートまでに動かず待つ秒数（`0` で即時）。動くかダメージを受けるとキャンセル。 |

- 文面は `plugins/Friend/messages_<language>.yml` でカスタマイズできます。
- データは `plugins/Friend/friends.db`（SQLite）に保存されます。
- 設定の変更を反映するにはサーバーを再起動してください。
