# Friend

[English](README.md)

フレンドどうしで共有チェストを使い、承認なしでテレポートできるMinecraftサーバー用プラグインです。

- `/friend add <名前>` で申請し、相手が承認するとフレンドになります。
- フレンド1組ごとに共有チェストが1つあり、`/friend chest <名前>` でどこからでも開けます。2人で同時に開いても中身は同じです。
- `/friend tp <名前>` で、相手の承認なしにフレンドのところへテレポートできます。
- Vault経由で、フレンドになるときに2人それぞれから手数料を取れます（任意）。

## 動作環境

- Spigot または Paper 1.20.4 以降（Paper 1.20.4・26.2・26.3 で動作確認）
- Java 17 以降（サーバーの版が求める版）
- 任意: 手数料を取るなら [Vault](https://github.com/MilkBowl/Vault) と経済プラグイン（EssentialsXなど）

## 導入

1. [Releases](https://github.com/spa77k/mc-friend/releases) から `friend-<版>.jar` をダウンロードします。
2. サーバーの `plugins/` フォルダに置きます。
3. サーバーを再起動します。`plugins/Friend/config.yml` ができます。
4. 日本語で表示するなら、`config.yml` の `language` を `ja` にして再起動します。

## コマンド

| コマンド | できること |
| --- | --- |
| `/friend` | 使い方を表示 |
| `/friend add <名前>` | フレンド申請を送る。相手がオンラインのときだけ送れます |
| `/friend accept [名前]` | 申請を承認する。申請が1件だけなら名前は省けます |
| `/friend deny [名前]` | 申請を断る |
| `/friend list` | フレンド（オンラインかどうか）と届いている申請を表示 |
| `/friend chest <名前>` | その人との共有チェストを開く |
| `/friend tp <名前>` | その人へテレポートする |
| `/friend remove <名前>` | フレンドを解消する |

### 申請と手数料

- 申請は `request-timeout` 秒で取り消されます。サーバーを再起動しても消えます。
- 相手から申請が来ているときに `/friend add` で申請し返すと、そのまま承認になります。
- 手数料は承認したときに2人それぞれから取ります。どちらかの所持金が足りなければフレンドにならず、お金も引かれません。
- 解消は無料で、払った手数料は戻りません。

### 共有チェスト

- 中身は、操作のたびと閉じたときに保存されます。
- 中身が残っている間や、どちらかが開いている間は、フレンドを解消できません。解消で中身が消えないようにするためです。

### テレポート

- `teleport-delay` 秒その場から動かないとテレポートします。動くかダメージを受けるとやめます。
- 相手がオンラインのときだけ使えます。ワールドへの入場制限などは、サーバー側の他のプラグインの設定に従います。

## 権限

| 権限 | 既定 | 内容 |
| --- | --- | --- |
| `friend.use` | 全員 | すべてのコマンドを使う |
| `friend.free` | なし | 手数料なしでフレンドになる（その人の分だけ無料） |

## 設定

`plugins/Friend/config.yml`

| キー | 既定値 | 内容 |
| --- | --- | --- |
| `language` | `en` | 使うメッセージファイル（`messages_<language>.yml`）。`en` と `ja` を同梱しています。 |
| `fee` | `500` | フレンドになるときに2人がそれぞれ払う額。`0` で無料。Vaultと経済プラグインがなければ常に無料です。 |
| `max-friends` | `10` | 1人のフレンドの上限。 |
| `request-timeout` | `300` | 申請の有効期限（秒）。 |
| `chest-rows` | `3` | 共有チェストの行数（1〜6）。減らすと、はみ出した中身のあるチェストは開けなくなります。 |
| `teleport-delay` | `3` | テレポートまでに動かず待つ秒数。`0` ですぐ飛びます。 |

文面はすべて `plugins/Friend/messages_<language>.yml` で変えられます。

設定の変更は、サーバーの再起動で反映されます。

## データ

フレンドと共有チェストの中身は `plugins/Friend/friends.db`（SQLite）に保存されます。ワールドと一緒にバックアップしてください。
申請・成立・解消のたびに、サーバーのログへ `Friend request: ...`、`Friends: ...`、`Friendship removed by ...` と記録されます。

## ビルド

```bash
mvn -B package
```

`target/friend-<版>.jar` ができます。
